## Overview
Use this API to create workspaces, chat with the AI, store artifacts, and stream events in real time. The API is designed for clients that render changes as they happen.

## Base URL
```
http://localhost:8001
```

## Authentication
No authentication required by default. For production, add Bearer token authentication via an API gateway.

<Note>
All endpoints return JSON except SSE streams which return `text/event-stream`.
</Note>

## Data model
Artifacts can store graph data using `application/vnd.graph+json`.

The graph is stored inside the artifact `content` field as a JSON string. That JSON contains `graph_type`, `nodes`, and `edges`.

<ResponseExample title="Graph JSON stored in artifact content">
```json
{
  "graph_type": "mind_map",
  "nodes": [
    { "id": "central_batteries", "label": "Battery Technology", "level": 0 },
    { "id": "core_manufacturing", "label": "Manufacturing", "level": 1 },
    { "id": "core_chemistry", "label": "Chemistry", "level": 1 },
    { "id": "branch_materials", "label": "Materials", "level": 2 },
    { "id": "detail_cathode", "label": "Cathode chemistry", "level": 3 }
  ],
  "edges": [
    { "id": "central_batteries_core_manufacturing", "source": "central_batteries", "target": "core_manufacturing", "relationship_type": "contains" },
    { "id": "central_batteries_core_chemistry", "source": "central_batteries", "target": "core_chemistry", "relationship_type": "contains" },
    { "id": "core_manufacturing_branch_materials", "source": "core_manufacturing", "target": "branch_materials", "relationship_type": "contains" },
    { "id": "branch_materials_detail_cathode", "source": "branch_materials", "target": "detail_cathode", "relationship_type": "contains" }
  ],
  "metadata": {
    "created_by": "assistant"
  }
}
```
</ResponseExample>

<ResponseField path="graph_type" type="string">
Graph type, e.g. `mind_map`.
</ResponseField>
<ResponseField path="nodes" type="array">
List of nodes.
</ResponseField>
<Expandable title="nodes[]">
  <ResponseField path="nodes[].id" type="string">Descriptive node ID (e.g., 'central_topic', 'core_concept_1').</ResponseField>
  <ResponseField path="nodes[].label" type="string">Short display label (2-5 words).</ResponseField>
  <ResponseField path="nodes[].level" type="integer">Hierarchy level: 0=central topic, 1=core concepts, 2=branches, 3=details, 4+=deeper.</ResponseField>
</Expandable>
<ResponseField path="edges" type="array">
List of edges.
</ResponseField>
<Expandable title="edges[]">
  <ResponseField path="edges[].id" type="string">Edge ID.</ResponseField>
  <ResponseField path="edges[].source" type="string">Source node ID.</ResponseField>
  <ResponseField path="edges[].target" type="string">Target node ID.</ResponseField>
  <ResponseField path="edges[].relationship_type" type="string">Relationship type.</ResponseField>
</Expandable>

## Workspaces
### Create a workspace
Creates a new workspace and emits a `workspace_created` event.

<ParamField body="title" type="string" required>
Workspace title.
</ParamField>
<ParamField body="project_id" type="string">
Optional project ID.
</ParamField>
<ParamField body="owner_id" type="string">
Optional owner identifier.
</ParamField>

<RequestExample>
```bash
curl -sS -X POST http://localhost:8001/workspaces \
  -H "Content-Type: application/json" \
  -d '{"title":"Research Hub"}'
```
</RequestExample>

<ResponseExample>
```json
{
  "id": "7b138f6c-2220-4e3e-9c90-2dfe4c9444c9",
  "title": "Research Hub",
  "project_id": null,
  "owner_id": null,
  "created_at": "2026-01-15T10:00:00Z",
  "updated_at": "2026-01-15T10:00:00Z"
}
```
</ResponseExample>

## Chat
### Stream chat responses
Streams SSE events as the AI generates mind maps.

<ParamField path="workspace_id" type="string" required>
Workspace ID.
</ParamField>
<ParamField body="message" type="string" required>
User message for the AI.
</ParamField>

<RequestExample>
```bash
curl -N -X POST http://localhost:8001/workspaces/7b138f6c-2220-4e3e-9c90-2dfe4c9444c9/chat \
  -H "Content-Type: application/json" \
  -d '{"message":"Create a mind map for battery manufacturing"}'
```
</RequestExample>

<ResponseExample>
```text
event: thinking_start
data: {"type":"thinking_start","content":""}

event: content
data: {"type":"content","content":"I will map the core stages..."}

event: tool_call
data: {"type":"tool_call","tool_name":"create_graph","arguments":{"title":"Battery manufacturing","graph_type":"mind_map"}}
```
</ResponseExample>

### List chat messages

<ParamField path="workspace_id" type="string" required>

</ParamField>
<ParamField query="limit" type="integer">

<RequestExample>
```bash

```
</RequestExample>

<ResponseExample>
```json
{
  "messages": [
    {
      "role": "user",

      "tool_call_id": null,
      "created_at": "2026-01-15T10:01:00Z"

  ]
}
```
</ResponseExample>

### Clear chat history

## Artifacts
### Create an artifact

<ParamField path="workspace_id" type="string" required>
Workspace ID.
</ParamField>
<ParamField body="type" type="string" required>
Artifact MIME type (e.g., `application/vnd.graph+json`).
</ParamField>
<ParamField body="title" type="string">
Artifact title.
</ParamField>
<ParamField body="content" type="string" required>
Artifact content as JSON string.
</ParamField>
